# Azure Global E-commerce Architecture - GitHub Template

This repository is a template that demonstrates a complete structure for designing and implementing a global e-commerce platform on Azure.
It includes:
- Functional & non-functional requirements
- Architecture documentation
- Terraform skeleton for AKS, Redis, Cosmos
- GitOps/Flux manifests and Helm chart placeholders
- CI/CD GitHub Actions workflows
- Runbooks
- Example microservices (catalog, cart, order) - simple Node.js services to demo structure
- Slide deck (pptx) placeholder

Use this repository as a starting point to implement your production environment.
